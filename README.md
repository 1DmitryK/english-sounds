# Soundroom — звуки британского английского

Русскоязычное приложение: 44 звука традиционной британской модели RP,
IPA, слова с переводом, поиск, фильтры и урок с произношением для каждого звука.

## Запуск

Откройте папку через локальный веб-сервер, например:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Сборка, установка пакетов и ключи API не нужны.
Открытие через file:// не поддерживается: браузер должен загрузить data.json.

## GitHub Pages

Файлы приложения находятся в корне. В Settings → Pages выберите Deploy from a branch,
ветку gh-pages (либо main) и папку /(root), затем Save.
Все внутренние адреса относительные: приложение работает и в подпапке проекта.
Файл .nojekyll отключает обработку Jekyll.

## Произношение и права

Для всех 44 звуков используются оригинальные видео BBC Learning English из серии
Pronunciation Tips. Канал: UCHaHD477h-FeBbVh9Sh7syA.
Список источников: sources/bbc-verified.json; также он доступен в самом приложении.
Проверены заголовки, авторство и разрешение встраивания всех роликов 31 октября 2026.

Видео демонстрирует сам звук, артикуляцию и примеры. Это учебное видео,
а не короткий отдельный аудиофайл. Объяснения диктора — на английском.
Видеозаписи и аудиодорожки не копируются, не извлекаются и не перераспространяются.
Используется оригинальный YouTube Privacy Enhanced Player, с управлением и ссылкой
на оригинал: https://support.google.com/youtube/answer/171780
Права на уроки принадлежат BBC; проект не связан с BBC.

Нужны интернет и доступ к YouTube. Возможны реклама, региональные ограничения
и изменение доступности автором. Есть ссылка для открытия оригинала на YouTube.
Закрытие урока удаляет плеер и останавливает воспроизведение.

Отдельные слова озвучиваются синтезом речи устройства, только голосом en-GB.
Если такого голоса нет, кнопка слова отключена; урок BBC остаётся доступен.
IPA не передаётся синтезатору. Американского режима нет.

Шрифты загружаются с Google Fonts; при недоступности используются системные шрифты.

## Проверки

воспроизведение уроков гласного, дифтонга и согласного; остановка плеера;
выбор исключительно en-GB и отсутствие подмены другим акцентом.

В репозитории только исходники приложения и ссылки на учебные материалы.
